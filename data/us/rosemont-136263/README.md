# Rosemont crimes datasets

Outerview crimes datasets for Rosemont (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Assault](assault.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/assault/rosemont-136263](https://outerview.ai/data/assault/rosemont-136263)
- [Battery](battery.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/battery/rosemont-136263](https://outerview.ai/data/battery/rosemont-136263)
- [Public Peace Violation](public-peace-violation.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/public-peace-violation/rosemont-136263](https://outerview.ai/data/public-peace-violation/rosemont-136263)
- [Weapons Violation](weapons-violation.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/weapons-violation/rosemont-136263](https://outerview.ai/data/weapons-violation/rosemont-136263)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
