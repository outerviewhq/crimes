# Harwood Heights crimes datasets

Outerview crimes datasets for Harwood Heights (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Assault](assault.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/assault/harwood-heights](https://outerview.ai/data/assault/harwood-heights)
- [Fraud](fraud.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/fraud/harwood-heights](https://outerview.ai/data/fraud/harwood-heights)
- [Harassment](harassment.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/harassment/harwood-heights](https://outerview.ai/data/harassment/harwood-heights)
- [Vandalism](vandalism.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/vandalism/harwood-heights](https://outerview.ai/data/vandalism/harwood-heights)
- [Vehicle Theft](vehicle-theft.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/vehicle-theft/harwood-heights](https://outerview.ai/data/vehicle-theft/harwood-heights)
- [Weapons Violation](weapons-violation.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/weapons-violation/harwood-heights](https://outerview.ai/data/weapons-violation/harwood-heights)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
