# Niles crimes datasets

Outerview crimes datasets for Niles (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Battery](battery.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/battery/niles-136142](https://outerview.ai/data/battery/niles-136142)
- [Burglary](burglary.geojson) — 3 rows. Full dataset: [https://outerview.ai/data/burglary/niles-136142](https://outerview.ai/data/burglary/niles-136142)
- [Identity Theft](identity-theft.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/identity-theft/niles-136142](https://outerview.ai/data/identity-theft/niles-136142)
- [Liquor Law Violation](liquor-law-violation.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/liquor-law-violation/niles-136142](https://outerview.ai/data/liquor-law-violation/niles-136142)
- [Trespassing](trespassing.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/trespassing/niles-136142](https://outerview.ai/data/trespassing/niles-136142)
- [Vandalism](vandalism.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/vandalism/niles-136142](https://outerview.ai/data/vandalism/niles-136142)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
