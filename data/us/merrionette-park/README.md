# Merrionette Park crimes datasets

Outerview crimes datasets for Merrionette Park (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Vandalism](vandalism.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/vandalism/merrionette-park](https://outerview.ai/data/vandalism/merrionette-park)
- [Vehicle Theft](vehicle-theft.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/vehicle-theft/merrionette-park](https://outerview.ai/data/vehicle-theft/merrionette-park)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
