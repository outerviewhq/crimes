# River Grove crimes datasets

Outerview crimes datasets for River Grove (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Burglary](burglary.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/burglary/river-grove](https://outerview.ai/data/burglary/river-grove)
- [Identity Theft](identity-theft.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/identity-theft/river-grove](https://outerview.ai/data/identity-theft/river-grove)
- [Motor Vehicle Burglary](motor-vehicle-burglary.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/motor-vehicle-burglary/river-grove](https://outerview.ai/data/motor-vehicle-burglary/river-grove)
- [Theft](theft.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/theft/river-grove](https://outerview.ai/data/theft/river-grove)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
