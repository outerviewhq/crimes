# Lake Forest Park crimes datasets

Outerview crimes datasets for Lake Forest Park (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Crimes datasets

- [Bribery](bribery.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/bribery/lake-forest-park](https://outerview.ai/data/bribery/lake-forest-park)
- [Drug Offense](drug-offense.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/drug-offense/lake-forest-park](https://outerview.ai/data/drug-offense/lake-forest-park)
- [Extortion](extortion.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/extortion/lake-forest-park](https://outerview.ai/data/extortion/lake-forest-park)
- [Forgery](forgery.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/forgery/lake-forest-park](https://outerview.ai/data/forgery/lake-forest-park)
- [Fraud](fraud.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/fraud/lake-forest-park](https://outerview.ai/data/fraud/lake-forest-park)
- [Narcotics](narcotics.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/narcotics/lake-forest-park](https://outerview.ai/data/narcotics/lake-forest-park)
- [Possession of Stolen Property](possession-of-stolen-property.geojson) — 1 rows. Full dataset: [https://outerview.ai/data/possession-of-stolen-property/lake-forest-park](https://outerview.ai/data/possession-of-stolen-property/lake-forest-park)
- [Theft](theft.geojson) — 2 rows. Full dataset: [https://outerview.ai/data/theft/lake-forest-park](https://outerview.ai/data/theft/lake-forest-park)

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
