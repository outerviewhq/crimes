# Tukwila crimes datasets

Outerview crimes datasets for Tukwila (US) for 2025.

Each GeoJSON file contains up to 1,500 records for one crimes category, ordered by date with the newest records first.

Public feature properties include the standard crimes fields plus flattened source attributes where available. Geometry is stored as the GeoJSON feature geometry.

## Public fields

Every feature includes `date`, `year`, `description`, `metadescription`, `address`, and `geometry`, with additional flattened source attributes where available.
